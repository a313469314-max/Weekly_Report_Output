# 后台数据报表生成器

全新独立的 Windows 可视化客户端，独立完成后台数据读取、汇总和 Excel 生成。

## 开发

```powershell
npm install
npm run typecheck
npm test
npm run dev
```

## 架构约束

- 终端用户只操作可视化客户端，不接触命令行、JSON 或接口参数。
- 后台登录使用可见浏览器，账号、密码和短信验证码只由用户手动输入。
- 只保存加密 Cookie，缓存时间不超过 7 天。
- 当前版本以运营后台结构化数据读取为唯一数据源；后台读取失败时会给出可理解的错误提示，不要求用户手工下载或导入文件。
- Excel 由本项目独立生成，采用当前版本的导出实现。
